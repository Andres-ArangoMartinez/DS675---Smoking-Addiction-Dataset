# Consequential decisions

Record agreements that affect the question, data version, evaluation, scope, or interpretation. Routine edits do not need an entry. Keep the current protocol in [methodology.md](methodology.md); this log explains why it changed.

No decisions are recorded yet. For a real agreement, add a short entry:

- **Date and decision:** `YYYY-MM-DD`, what was agreed or changed.
- **Reason:** why, including the main alternative if relevant.
- **Participants and evidence:** who took part; links to discussion, source, code, or experiment.

If replacing an earlier decision, link it and mark it superseded rather than deleting its history.
