PROJECT CONTEXT

We are developing a supervised machine learning project using the
Smoking Addiction Dataset described in our existing Milestone 2
proposal.

Our proposed research direction is to compare how psychological
measurements, daily habits, and historical craving and nicotine-use
information contribute to predicting Overall_Craving_Score.

Next-day prediction for known participants is a candidate scenario,
but the team has not yet finalized the prediction horizon,
evaluation population, feature groups, or experimental protocol.

Clearly distinguish proposed choices from agreed decisions.

COLLABORATION WORKFLOW

In CONTRIBUTING.md, explain this lightweight workflow:
1. Define a small task in a GitHub Issue.
2. Identify a responsible member, a reviewer, and a completion
   criterion.
3. Create a short-lived branch named after the task.
4. Make focused changes.
5. Open a pull request explaining the changes and verification.
6. Have another teammate review before merging into main.

Explain these conventions:
- work/<name>/ is for individual exploration.
- Reviewed reusable code belongs in src/.
- Integrated analyses belong in notebooks/.
- Recorded experiment outputs belong in results/.
- Report writing takes place in the LaTeX section files.
- Main contains the reviewed, integrated project.
- Avoid editing the same notebook simultaneously.
- Avoid duplicated datasets and competing copies of shared
  preparation and evaluation code.

Describe Issues and pull requests, but do not create any remotely.
